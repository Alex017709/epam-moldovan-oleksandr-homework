# EPAM IT-Марафон 2026 — Домашнє завдання #1

## User Stories для перегляду групного бронювання

### US 1: Зведений перегляд замовлень групи
**Як** організатор бронювання,  
**я хочу** переглядати зведену інформацію про попередні замовлення всіх учасників моєї групи на одному екрані,  
**щоб** швидко оцінити загальний обсяг замовлення та переконатися, що всі учасники зробили вибір.

**Acceptance Criteria:**
1. **AC 1:** На екрані відображається список усіх учасників групи з їхніми обраними позиціями та вартістю.
2. **AC 2:** Наявний блок із підсумковою загальною сумою та кількістю товарів/послуг для всієї групи.
3. **AC 3:** Біля кожного учасника відображається статус його вибору (*«Готово»* / *«В процесі»*).

---

### US 2: Фільтрація та перевірка деталей
**Як** організатор бронювання,  
**я хочу** мати можливість фільтрувати та сортувати замовлення учасників групи на екрані зведеного перегляду,  
**щоб** легко перевіряти наявність конкретних позицій та деталі замовлення.

**Acceptance Criteria:**
1. **AC 1:** Наявний фільтр за статусом замовлення та категоріями обраних позицій.
2. **AC 2:** Наявна стрічка пошуку за ім'ям або прізвищем учасника.
3. **AC 3:** При натисканні на картку учасника відображаються його детальні примітки та вибір.
